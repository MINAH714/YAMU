# EXP-006: 생활비 거래로 6개월 비교

[색인](../README.md)

사용자 요청에 따라 이전 EXP-006을 교체한다. EXP-007을 만들거나 이전 EXP-006 결과를 별도로 보관하지 않는다. EXP-001~005는 변경하지 않는다.

최종 위임 범위는 실적을 보장하기 위한 추가 결제나 카드 강제 배정 없이 생활 패턴에 따라 거래를 생성하는 것이다. 실적 충족은 결과에서 확인하며, 미달했다고 입력을 수정하지 않는다. 이 문서는 본 비교 실행 전에 작성했다. 거래와 생성 설정은 사전 검사에서 이미 고정했다.

## 실행 전에 고정한 조건

- 카드: 신한카드 처음, KB국민 청춘대로 톡톡카드. 기간: 2026년 11월~2027년 4월.
- 1인 직장인의 합성 소비: 평일 출퇴근, 월 18회 점심, 주 1회 장보기, 월 8회 카페·8회 편의점, 월 2회 택시·2회 생활용품, 격월 의류, 월 1회 구독.
- 월 예산 상한 135만 원, 생성 시드 6006. 범위 내 금액과 날짜를 한 번 생성한다. 예산 초과 시 중단하며 유리한 시드를 다시 찾지 않는다.
- 첫 달 전월 실적은 두 카드 각각 40만 원, 혜택 사용량 0, 정상 결제 상태, 카드별 월 결제 가능액 1,000만 원. 다음 달부터 각 전략에서 실제 인정된 실적을 이월한다. 매월 전액 납부한다.
- 등록된 2026년 11월 정책을 6개월 유지한다는 테스트 가정이다. 운영 정책·계산기는 수정하지 않고 테스트 어댑터에서 유효기간만 확장한다.
- 처음만 사용, 톡톡만 사용, 업종별 고정 사용(카페는 톡톡, 나머지는 처음), YAMU, 균등 랜덤 100개 시드(0~99)를 비교한다. 각 경로는 독립 상태이며 미래 거래를 사용하지 않는다. 실적을 채우려고 선택을 바꾸지 않는다.
- 기본 카드는 처음이다. YAMU 동률 처리도 기존 추천 로직을 그대로 사용한다. 랜덤은 Java Random.nextInt(2)를 거래마다 한 번 호출한다.

## 거래 사실과 계산 범위

금액 범위·빈도·브랜드·명시한 사실은 [고정 설정](frozen-spec.json), 전체 거래는 [고정 거래](frozen-transactions.json)에 있다. 가격은 합성 입력이며 실제 요금이나 국민 평균을 주장하지 않는다. 주말은 구분하지만 공휴일·휴가·거리·계절성은 모델링하지 않는다. 주거비 등 카드 외 지출은 포함하지 않는다.

지하철은 모바일 후불 교통으로 명시하여 기존 실적 규칙에 따라 당월에 인정한다. 택시는 직접 결제, 구독은 국내 원화 정기 결제다. 세금·상품권·충전·취소·이자·포인트 사용 등 제외 사유가 없는 합성 거래임을 명시했다. 교통·택시 가맹점 두 개는 일회용 테스트 DB에만 추가하며 상품의 혜택 대상은 바꾸지 않는다. 일반 구매 보조 함수가 자동으로 채우지 않는 교통 등의 사실은 입력에서 명시한다. 앱에서 이 사실들이 자동 수집된다는 검증은 아니다.

실적 미달로 적용 대상이 아닌 한도가 null인 경우 값을 만들지 않는다. 해당 한도를 쓰는 모든 혜택이 실적 조건에서 제외됨을 확인하고 기존 계산기의 정상 0원 결과와 기록을 남긴다. 적용 혜택이나 인정 실적을 계산할 수 없으면 실행을 실패시킨다.

## 검증·기록

거래별 두 카드 × 전월 실적 0·299,999·300,000·400,000·500,000·1,000,000원 × 미사용·1원 잔여·완전 소진을 검사한다. 월 이월, 일·월 한도 구분, 톡톡 할인 거래의 실적 제외, 대표 스타벅스 거래 수식을 검산한다. 본 비교는 104경로를 실행하고 YAMU 재실행 해시가 같은지 확인한다. 독립 수식 검산은 거래별 후보 혜택·선택·실적·난수 매핑·한도 차감을 확인한다.

실행마다 고유 폴더에 설정·입력·소스와 정책 압축본·해시·상태·결과를 남긴다. 보고서에는 월별 소비액과 업종 구성, 월별 카드 실적·다음 달 자격, 전체 전략과 랜덤 분포를 포함한다. 동률이나 YAMU가 낮은 결과도 공개한다. 본 결과를 보고 거래·규칙을 수정하지 않는다.

변경 파일: 테스트 `CardSelectionSixMonthSupport.java`, `CardSelectionSixMonthTest.java`, 입력 `card-selection-exp-006.json`, 이 실험 폴더, 상위 색인과 기록 점검표. EXP-001~005 원본·서비스 코드·Jira·외부 문서·MR은 변경하지 않는다. 커밋·push는 이번 범위에 없다.
