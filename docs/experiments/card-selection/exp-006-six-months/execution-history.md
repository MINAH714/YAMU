## 월별·누적 차액 추가 집계 (2026-11-13)

사용자가 최신 결과로 비교군별 월별·누적 차액 표와 그래프를 요청했다. 기존 본 실행의 monthly.json과 summary.json을 읽어 집계했으며 테스트를 다시 실행하거나 카드·거래·정책·전략을 바꾸지 않았다.

`Analyze-Differences.ps1`은 103개 비교 경로(고정 2·업종별 1·랜덤 100)의 618개 경로·월 항목과 평균 24개 항목을 검산한다. 누적 차액 항등식, 각 경로·YAMU의 원 summary 합계 일치를 확인했다. 랜덤 분포는 각 시드의 연속 누적 차액에서 산출했다.

새 [차액 보고서](differences.md), 실행 폴더의 difference-analysis/ 아래 CSV·집계표·검산 JSON·PNG 2개를 추가하고 색인·점검표에 연결했다. 그래프의 음수 구간·0 기준선·한글·범례를 이미지로 확인했다. 표시 정확도를 위해 마지막 값의 소수점 반올림을 없애고 재생성했으며 수치 결과는 변하지 않았다. 집계 실패나 본 실험 재실행은 없었다. 적용한 분석 코드와 원자료 해시는 difference-analysis/validation.json에 있다.

## MR 공개 준비 (2026-11-13)

사용자가 톡톡만 사용 대비 6개월 추가 혜택 11,300원·19.3%를 발표 문구로 선택하고 기존 MR !308에 반영하도록 승인했다. 보고서·차액 문서·색인에 비교 대상, 기간, 합성 조건, 증가율 계산식과 환급률이 아니라는 설명을 추가했다. 다른 비교군·음수 차액·랜덤 9경로 대비 열세는 그대로 남겼다.

공개 준비에서는 기존 결과를 독립 수식으로 다시 검산하고 보존 압축본의 해시를 확인했다. 본 실험을 새로 실행하거나 입력·정책·선택 규칙을 바꾸지 않았다. EXP-006은 합성 데이터만 포함한다. EXP-005 비공개 원자료는 추가하지 않는다. 앞 절의 커밋·MR 변경 없음은 각 실험·집계 단계의 범위이며, 이번 요청은 관련 변경의 커밋·push·기존 MR 갱신을 별도로 승인한 것이다. 승인·Merge·Jira 변경은 포함하지 않는다.
