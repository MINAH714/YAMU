# MR 공개 전 개인정보 점검

## 공개에서 제외한 자료

- 실제 명세서 HTML·이미지, 카드 표시 일부, 원본 파일 해시와 로컬 경로
- 개인별 거래 날짜·시각·가맹점·금액·행 번호, 거래별 선택과 한도 변화
- 실제 전월 실적과 금융기관 등 개인 계좌 관련 정보
- 실제 입력의 상세 JSON/CSV, 이를 담은 ZIP, 과거 문서·작업 폴더 보존 목록
- 개인 자료에 고정된 명세서 파서·사전 검사·REAL_CASE 실행 코드와 설정

원본은 기존 로컬 작업 폴더에 그대로 두었으며 공개 브랜치의 커밋 이력에도 넣지 않았다. 삭제한 자료를 나중 커밋에서 숨기는 방식이 아니다.

## 공개한 자료

EXP-001~004는 합성 데이터 실험이므로 입력과 결과를 보존했다. EXP-005는 58건이라는 건수, 정책 모델별 총포인트·차액·범위와 해석만 공개한다. 행별 소비 정보와 결합할 수 있는 자료는 포함하지 않는다. 집계 값도 외부 정보와 결합하면 추정 가능성이 완전히 사라지는 것은 아니므로 완전한 익명화를 보장한다고 표현하지 않는다.

EXP-005 합성 코드의 개인 자료에서 유래한 수치도 별도의 가상 거래액과 실적값으로 교체했다. 공개된 합성 A/B 값은 실제 사례의 A/B 값이 아니다. 실제 실행 진입점과 원본 승인 설정은 포함하지 않으며 REAL_CASE 차단 검증은 유지한다.

## 검증 방법

추가 파일 및 ZIP 내부를 개인 식별 일부·개인 실적·원본 해시·로컬 사용자 경로·자격증명 패턴으로 검사한다. 집계 CSV가 원본과 동일한지 확인한다. 합성 테스트와 보존 ZIP 해시 검사 결과는 [공개본 검증 기록](publication-validation.md)에 남긴다.

공개하지 않는 자료 때문에 EXP-005의 실제 거래별 검산을 이 MR만으로 독립 재현할 수 없다. 이 제한을 결과 보고서에도 명시한다.
