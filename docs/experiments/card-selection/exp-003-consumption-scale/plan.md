# EXP-003 사전 조건과 승인 범위

사용자는 EXP-001·002가 월 한도를 모두 채워 동률이었다는 점을 바탕으로 한도 미소진 조건의 별도 실험을 요청했다. 아래 다섯 배율과 두 카드 집합, 기존 전략 유지 계획을 제시했고 사용자가 구현·실행을 승인했다. 실행 전에 `card-selection-exp-003.json`을 작성했으며, 각 실행의 frozen-scale-plan.json과 manifest의 SHA-256으로 보존한다. 이 문서는 그 승인 범위를 정리한 설명이며 입력 원본을 대신하지 않는다.

## 질문

같은 보유 카드·가맹점·시각·순서에서 모든 거래 금액만 일괄 줄였을 때, 선택 방식별 총혜택과 한도 사용률은 어떻게 달라지는가?

| 배율 | 총 소비액 | 의도 |
|---|---:|---|
| 10% | 30,900원 | 어느 전략에서도 월 한도를 채울 수 없는 구간 |
| 15% | 46,350원 | 어느 전략에서도 월 한도를 채울 수 없는 구간 |
| 25% | 77,250원 | 일부 한도 소진 가능 |
| 50% | 154,500원 | 중간 규모 |
| 75% | 231,750원 | 기존 규모에 가까운 구간 |

100%는 EXP-001·002의 보존된 결과를 참고값으로만 표시한다. 배율 추가·교체, 업종별로 다른 배율 적용, 거래 삭제·순서 변경·카드 교체는 하지 않는다. 전부 원 단위 정수이므로 금액 축소를 위해 반올림하지 않는다.

## 고정 조건

- 기존 24건의 날짜·시각·가맹점·채널·순서 유지. 소비액 외의 조건은 기존 실험과 동일.
- 카드 집합은 처음·톡톡 2장 및 처음·톡톡·LOCA LIKIT Eat 3장.
- 전월 실적 카드별 400,000원, 당월 실적·한도 사용량 0, 가용 신용한도 카드별 10,000,000원, ACTIVE/NORMAL, 기본 카드 처음.
- 신규 유예 종료·국내 일반 직접 구매·일시불·정상 승인 가정. 2장은 EXP-001 사실, 3장은 EXP-002에서 승인된 명시 사실까지 재사용. 신규 거래 사실이나 정책을 만들지 않음.
- 카드별 고정 사용, YAMU, 업종 규칙, java.util.Random의 시드 0~99 균등 선택.
- 2장 업종 규칙: 카페 톡톡, 나머지 처음. 3장: 음식점 LOCA, 카페 톡톡, 편의점·온라인쇼핑 처음. 한도 소진 후에도 고정.
- 상태는 전략·시드·배율·카드 집합별 독립. 기존 계산기·정책 로더·실적 해석기·추천 선택기를 사용하고 실험 장부만 새 테스트로 구성.
- 배율당 104+105회, 총 1,045회 본 비교. 검산과 결정적 재실행은 별도 검사이며 표본에 추가하지 않음.

## 한도 미소진의 사전 근거

15%에서 한 카드에 대상 소비를 전부 몰아도 처음은 전체 소비 46,350×5%=2,317.5P 이하(월 5,000P), 톡톡 스타벅스 5,700×50%=2,850원 이하(월 10,000원), LOCA 음식점+카페 17,550×60%=10,530원 이하(월 13,000원)다. 실제 지급 단위 적용 전의 상한이며 실행 결과가 아니다. 10%는 더 작다.

이 구간에서는 월 한도가 어떤 전략에서도 소진되지 않아야 한다. 테스트가 이를 검사한다. 다만 거래별 지급 단위·최소 결제액은 별도로 확인한다. 정상 0원과 계산 불가를 구분하며 미정 정책 때문에 조건을 바꿔야 하면 먼저 사용자에게 보고한다.

## 검사·출력·해석

각 배율·집합의 초기/부분 소진/완전 소진 및 실제 순차 상태에서 모든 카드를 평가한다. 대표 음식점·스타벅스는 독립 수식으로 검산한다. 같은 카드 수·같은 시드는 배율을 바꿔도 동일한 선택 인덱스를 만들어야 한다. 카드 수가 다르면 nextInt의 매핑도 다르다.

전체 전략 총혜택·소비 대비 혜택률·YAMU 차액, 랜덤 분포, 일/월 한도 사용률과 최초 소진 거래, 거래별 선택·혜택·실적·한도, 계산 불가 건수를 보존한다. 3장−2장과 같은 집합 내 YAMU−업종 규칙을 분리한다. 모든 배율을 공개하고 다섯 조건의 평균을 사용자 평균으로 표시하지 않는다.

월 한도 경쟁이 없고 미래 혜택 자격도 변하지 않는 조건에서는 즉시 최대 선택의 우위가 예상된다. 이 결과만으로 미래 소비를 고려하는 최적화 능력을 입증했다고 해석하지 않는다. 전월에는 실적을 충족했지만 이번 달 소비가 줄어든 한 달이며, 다음 달 실적 유지 효과는 검증하지 않는다.

## 파일·원본 보존
