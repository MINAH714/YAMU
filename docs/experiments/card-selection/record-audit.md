# 실험 기록 공개본 점검표

[색인](README.md) · [개인정보 점검](privacy-review.md)

이 문서는 공개용 점검표다. 개인 정보가 들어 있던 과거 전체 점검표와 작업 폴더 목록은 로컬에 보존하며 이 MR에는 포함하지 않는다.

| 항목 | 공개본 상태 |
|---|---|
| EXP-001~004 목적·계획·승인 범위 | 각 실험 보고서와 사전 계획에 보존 |
| 입력·카드·정책·코드 버전 | 합성 입력과 실행별 보존 코드·해시 포함 |
| 거래별 혜택·한도·랜덤 분포 | 각 실행 폴더와 압축 원자료 포함 |
| 수동 선택과 동률·업종별 고정 대비 열세 | 종합 문서에 모두 포함 |
| EXP-005 결과 | 정책 12조건의 집계 CSV 및 해석만 공개 |
| EXP-005 실제 입력·초기 상태·식별값·재생 설정 | 개인정보 보호를 위해 미포함, 원본은 로컬 보존 |
| EXP-005 검산·실행 이력 | 원본의 검산 결과를 요약, 개인 거래별 검산 자료는 미포함 |
| 공개 코드 검사 | publication-validation.md에 이번 실행 결과 기록 |
| 실사용자 후속 실험 | 사용자 결정에 따라 취소. 모집·실행하지 않음 |
| 확인되지 않은 과거 과정 | 기록 미확인으로 유지. 추정하지 않음 |

공개본 합성 테스트의 거래·실적 값은 개인 자료와 무관한 값으로 변경했다. 개인정보 공개 준비를 위한 변경이며 EXP-005의 실제 실험 조건이나 보존 결과를 다시 계산한 것이 아니다.
