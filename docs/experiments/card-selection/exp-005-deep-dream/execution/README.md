## 해석과 검산 기록

이미 57건은 같은 카드를 사용하고 있었으므로 개선이 작았다. 검토한 업종 대안에서도 카드 선택과 같은 조건 내 차액은 유지됐지만 총포인트는 달라졌다. 가능한 조합을 모두 실행한 것이 아니라 한도가 소진되지 않는지와 카드 간 혜택 차이를 수식으로 검증했다.

원본 기록에서는 후보 평가 5,568건, 24개 경로, 정책 12조건의 공동 범위를 독립 검산했다. 이 숫자는 원본 검산 이력이며, 이번 MR 준비에서 실제 거래를 다시 실행한 것이 아니다. 거래별 검산 자료와 상세 실행 이력에는 개인 정보가 있으므로 공개하지 않는다.

월초 사용량 0, 목록 밖 공유 사용 제외, 결제 가능 상태, 일반 구매 등 승인된 가정에 따른 결과다. 챙겨드림 및 다음 달 실적 등을 포함한 월 최종 혜택, 실제 카드사 지급액, 해외 비용 포함 순이익은 검증하지 않았다. 한 사례에 정책 가정을 바꾼 12조건이며 사용자 12명이 아니다. EXP-004의 수동 동률이나 EXP-003의 불리한 결과를 대체하지 않는다.

## 공개 코드와 재현 제한

정책 어댑터·격리 DB 시드 검사·합성 거래의 상태 갱신·A/B·복수 불확실성 검증 코드를 포함한다. 실제 자료와 연결되는 실행기·원본 설정·행별 입력·압축 결과는 제외했다. 공개 합성 테스트의 수치를 실제 사례 수치로 해석하면 안 된다.

공개본만으로 실제 58건을 재현하거나 거래별 결과를 독립 검산할 수 없다. 원본은 로컬에 보존한다. 실사용자 후속 실험은 진행하지 않는다.
