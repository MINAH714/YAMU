# 영업일 계산 (holiday)

청구 출금일, 할부 회차 출금일, 환급 기한, 잔고예보의 가상 청구 일정이 같은 규칙으로 영업일을 세도록 공통 계산기를 둡니다(`com.yamu.be.global.calendar`).

| Task | 내용 | 상태 (2026-11-02) |
|---|---|---|
| 5.4.5 (S15P31E103-210) | 영업일 계산기, 내장 공휴일 파일(2026·2027) | 작업 중 |
| 5.4.6 (S15P31E103-211) | 공공데이터 특일 정보 API로 공휴일 동기화 | 해야 할 일 |

- 기준: 결제 정책 초안 4-3(결제일이 비영업일이면 다음 영업일, POL-005·FR-067), 10/21 결제 정책 회의(영업일은 토·일·공휴일을 뺀 날, 환급 3영업일)

## 쓰는 법

`BusinessDayCalendar` 빈을 주입받아 씁니다. 날짜는 모두 **한국 날짜**(`LocalDate`)입니다. UTC 시각에서 날짜를 뽑을 때는 `ZoneId.of("Asia/Seoul")`로 바꾼 뒤 넘깁니다.

| 메서드 | 결과 | 예 |
|---|---|---|
| `isBusinessDay(date)` | 토·일·공휴일이 아니면 true | 2026-10-09(금, 한글날) → false |
| `businessDayOnOrAfter(date)` | 영업일이면 그날, 아니면 그 뒤 첫 영업일 | 결제일 2026-09-24(추석 연휴) → 2026-09-28(월) |
| `plusBusinessDays(date, n)` | 기준일 다음 날부터 영업일을 n개 센 날. 기준일은 세지 않음. n은 1~366 | 2026-12-30(수) + 3 → 2027-01-05(화) |

```java
LocalDate withdrawalDate = calendar.businessDayOnOrAfter(paymentDate);   // 청구 출금일
LocalDate refundDueDate = calendar.plusBusinessDays(canceledOn, 3);      // 환급 기한
```

## 규칙

- **쉬는 날:** 토요일, 일요일, 공휴일 파일에 있는 날(대체공휴일·선거일 포함)
- **노동절(5월 1일):** 2026년부터 관공서 공휴일이라 쉬는 날입니다. 2026-04-28 국무회의에서 「관공서의 공휴일에 관한 규정」 개정이 의결됐고, 노동절은 2026-05-01, 제헌절은 2026-05-11부터 시행됐습니다.
- **임시(1차):** 12월 31일처럼 관공서 공휴일이 아닌 날은 영업일로 셉니다. 은행·카드사가 따로 쉬는 날을 반영할지는 정해지지 않았습니다.
- **데이터가 없는 해:** 주말만 쉬는 날로 계산하고 `{연도}년 공휴일 데이터가 없어 …` 경고를 해마다 한 번 남깁니다. 서버는 그대로 뜹니다.
- **데이터 파일이 잘못됐을 때:** 서버가 뜨지 않습니다. 파일 이름과 `year`가 다르거나, 다른 해 날짜·같은 날짜 두 번·빈 목록·없는 날짜(2026-02-30)가 있는 경우입니다. 출금일이 틀린 채로 계산되는 것보다 바로 드러나는 편이 낫기 때문입니다.

## 공휴일 파일

`be/src/main/resources/holidays/{연도}.json`. 일요일과 겹친 공휴일도 넣어 달력과 그대로 대조할 수 있게 합니다.

```json
{
  "year": 2027,
  "source": "우주항공청 「2027년 월력요항」(2026-06-29 발표) ...",
  "holidays": [
    { "date": "2027-01-01", "name": "1월 1일" },
    { "date": "2027-02-09", "name": "대체공휴일(설날)" }
  ]
}
```

| 파일 | 출처 | 확인 |
|---|---|---|
| `2026.json` (22일) | 우주항공청 「2026년 월력요항」 + 노동절·제헌절 공휴일 지정 | 일요일 52일 + 일요일이 아닌 공휴일 20일 = 72일 |
| `2027.json` (24일) | 우주항공청 「2027년 월력요항」(2026-06-29). 어린이날·부처님오신날은 보도자료 본문에 없어 한국천문연구원 달력자료로 채움 | 72일(보도자료와 같음) |

`EmbeddedHolidaysTest`가 해마다 "일요일이 아닌 공휴일 20일"을 확인합니다. 파일을 고치면 이 숫자도 공식 발표와 맞는지 같이 고칩니다.

### 갱신

- **다음 해:** 우주항공청이 매년 6월쯤 다음 해 월력요항을 발표합니다. 발표되면 `{다음 해}.json`을 추가하고 합계 테스트를 늘립니다. 12개월 할부를 생각하면 올해와 내년 파일이 늘 있어야 합니다.
- **임시공휴일·선거일:** 국무회의에서 임시공휴일이 지정되면 그 해 파일에 추가합니다. 5.4.6이 끝나면 공공데이터 API가 자동으로 받아오고, 이 파일은 API를 못 쓸 때의 대비가 됩니다.
- 이미 확정된 청구서의 출금일을 공휴일 변경에 맞춰 다시 계산할지는 5.4.3에서 정합니다.
