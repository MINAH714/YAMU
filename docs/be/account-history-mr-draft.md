## 📝 작업 내용 요약

과거 자산 흐름이 매번 금융망 응답만 읽고 기준 잔액을 저장하지 않아 무거래 구간을 확인할 수 없었다. 계좌별 실제/합성 stream, 원장, 동기화 실행, 시작 잔액 근거를 포함한 완전 조회 범위를 4개 테이블에 저장하고 API는 DB에서 재계산한다. 오늘과 예보는 기존 계산을 유지한다.

외부 조회는 DB 트랜잭션 밖에서 수행한다. 재시도는 외부 거래 ID UNIQUE와 내용 해시로 확인하며 같은 ID의 다른 내용·기존 거래 누락은 원본을 보존하고 종속 잔액 근거를 무효화한다. 동시 실행은 계좌 초기화 잠금과 실행 세대 검사로 이전 결과 확정을 막는다. 무거래는 완전 조회와 검증된 인접 잔액이 있어야 표시한다.

QA 전용 CLI는 소비 시드와 명시한 합성 자금 흐름을 참고해 실제 시작 경계와 종료 잔액을 맞춘다. 음수 시작·중간 잔액을 숨기는 보정 거래는 만들지 않는다. 자산 전용 reset/purge는 QA stream만 지운다. Android는 SIMULATED를 실제 잔고와 구분해 그래프·날짜 띠·범례·접근성에 표시한다.
