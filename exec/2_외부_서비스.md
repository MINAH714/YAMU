# 2. 외부 서비스 정보

YAMU가 코드나 배포에서 실제로 쓰는 외부 서비스입니다. 키·토큰 값은 적지 않고, 어디에 넣는지만 적습니다.

## 서비스가 직접 부르는 API

### SSAFY 금융망 API (필수)

계좌 조회, 1원 인증, 잔액·거래내역 조회, 체크카드 결제 출금, 카드값 출금에 씁니다. 실제 은행이 아니라 SSAFY 교육용 금융망이며, 모든 계좌·잔액·입출금의 원본입니다.

| 항목 | 내용 |
|---|---|
| 주소 | `https://finopenapi.ssafy.io/ssafy/api/v1` (`application.yml`의 `yamu.fin-api.base-url`) |
| 가입 · 발급 | SSAFY 교육생에게 제공되는 금융 API 사이트에서 앱을 등록하고 API 키를 받습니다. 팀 노션 「API 명세」 4장에 절차가 있습니다 |
| 넣는 곳 | 운영: 환경 변수 `SSAFY_API_KEY` / 로컬: `application-local.yml`의 `yamu.fin-api.api-key` |
| 고정 헤더 값 | `institutionCode=00100`, `fintechAppNo=001` (`be/.../global/finapi/FinApiClient.java`) |
| 사용자 키 | 금융망 회원마다 받는 `userKey`는 DB `app_user.ssafy_user_key`에 암호화해 저장합니다 |
| 쓰는 API | 수시입출금 계좌 목록·잔액·거래내역 조회, 1원 송금 인증(`openAccountAuth`·`checkAuthCode`), 출금(`updateDemandDepositAccountWithdrawal`), 입금(`updateDemandDepositAccountDeposit`). 시드 도구만 회원 생성·조회(`/member`)를 씁니다 |
| 실패 처리 | 응답이 없거나 시간이 넘으면 "결과 불명"으로 두고, 복구 작업(`PAYMENT_RECOVERY_ENABLED`)이 거래내역의 태그로 출금 여부를 확정합니다 |

주의: `BILLING_JOBS_ENABLED=true`인 서버는 청구일에 금융망에서 실제로 카드값을 출금합니다. 로컬에서 운영 DB 복사본으로 실행할 때는 `BILLING_JOBS_ENABLED`, `PAYMENT_RECOVERY_ENABLED`, `NOTIFICATION_JOBS_ENABLED`를 `false`로 둡니다.

### 공공데이터포털 — 한국천문연구원 특일 정보 (선택)

카드값 출금일·청구일을 영업일로 맞추려고 공휴일을 받습니다. 키가 없으면 저장소에 들어 있는 공휴일 파일을 씁니다.

| 항목 | 내용 |
|---|---|
| 주소 | `https://apis.data.go.kr/B090041/openapi/service/SpcdeInfoService` |
| 가입 · 발급 | [공공데이터포털](https://www.data.go.kr/data/15012690/openapi.do)에서 「한국천문연구원_특일 정보」 활용 신청 → 마이페이지 → 데이터활용 → Open API → 활용신청 현황에서 **일반 인증키(Decoding)** 복사 |
| 넣는 곳 | 운영: `DATA_GO_KR_SERVICE_KEY` (`infra/.env.prod`) / 로컬: `yamu.holiday.service-key` |
| 호출량 | 서버 한 대에 하루 24건(2개 연도 × 12개월). 개발계정 한도 하루 10,000건 |
| 자세히 | `docs/be/holiday.md` |

## 인프라 · 배포에 쓰는 서비스

| 서비스 | 용도 | 설정 · 자격증명 위치 |
|---|---|---|
| AWS EC2 (SSAFY 제공) | BE·Redis·AI 컨테이너, Nginx, Jenkins를 올린 서버 (Ubuntu 24.04) | SSAFY가 발급한 접속 키. 팀원 PC의 SSH config 별칭 `ec2` |
| AWS RDS (팀 AWS 계정) | 운영 MySQL 8.4.11 (서울 리전, TLS 필수, 자동 백업 7일). 보안그룹은 EC2 공인 IP 하나만 허용 | 서버 `infra/.env.rds`, `/home/ubuntu/.config/yamu/rds/`. 관리자 비밀번호는 RDS 관리형 Secrets Manager. 생성 절차 `docs/infra/rds.md` |
| AWS Secrets Manager | 운영 키(암호화·JWT·금융망·POS)의 원본 보관 | 팀 AWS 계정 |
| AWS S3 | Jenkins가 만든 mock APK 보관(비공개 버킷, 24시간 다운로드 링크) | Jenkins 자격증명 `yamu-apk-s3-credentials`. `infra/android/README.md` |
| AWS CloudFront | 카드 이미지 제공. BE는 주소만 만들어 앱에 주고 직접 부르지 않습니다 | `YAMU_CARD_IMAGE_BASE_URL` (기본값 있음) |
| 도메인 `yamu.it.kr` | 서비스 주소 | DNS A 레코드 → EC2 공인 IP |
| Let's Encrypt (certbot) | HTTPS 인증서, HTTP-01 방식, 자동 갱신 | 서버 `/etc/letsencrypt/live/yamu.it.kr/`. `docs/infra/nginx.md` |
| GitLab (`lab.ssafy.com`) | 저장소 `s15-final/S15P31E103`, MR, 파이프라인 상태 표시 | Jenkins 자격증명 `gitlab-yamu-read`(read_repository 토큰), `yamu-gitlab-status-api`(api 토큰). GitLab CI/Runner는 쓰지 않습니다 |
| Jenkins (자체 설치) | CI(develop), CD(master), MR 검사, APK 빌드 | 서버 컨테이너, Tailscale 주소의 8081 포트로만 접속. `docs/infra/jenkins.md` |
| Tailscale | Jenkins 관리 화면과 CD 트리거를 공인망에 열지 않으려고 사용 | 팀원 기기를 같은 tailnet에 추가 |
| Mattermost (SSAFY) | CI/CD 결과·배포 승인 요청 알림. 채널 `야무_CI/CD` | Incoming Webhook URL → Jenkins 자격증명 `yamu-mattermost-webhook`. `docs/infra/jenkins-notifications.md` |
| Docker Hub 이미지 | `eclipse-temurin`, `mysql`, `redis`, `python`, `jenkins`, `node`, Grafana·Prometheus·Loki 등 | 공개 이미지, 계정 불필요 |

## 앱에 들어간 외부 라이브러리 서비스

| 서비스 | 용도 | 비고 |
|---|---|---|
| Google ML Kit Barcode Scanning (17.3.0) + CameraX | 모의 POS 앱에서 고객 결제 코드(QR·바코드) 읽기 | 기기 안에서 동작, 키·가입 불필요. `pos` flavor에만 포함 |
| Google Play services `auth-api-phone` (18.2.0) | 문자 인증번호 자동 입력(SMS User Consent) | 키·가입 불필요 |

## 쓰지 않는 것

- **문자 · 본인인증 업체:** 연동하지 않았습니다. 인증번호는 문자 대신 API 응답의 `demoCode`로 돌려줍니다.
- **소셜 로그인 · 결제 대행(PG) · 카드사 API:** 없습니다. 결제 승인은 BE 안의 모의 승인 엔진이 하고, 실제 돈은 SSAFY 금융망에서만 움직입니다.
- **푸시(Firebase FCM):** 연동하지 않았습니다. 알림은 앱 안 알림함으로만 보여 줍니다.
- **LLM(생성형 AI) API:** 쓰지 않습니다. 생활비 예측 AI는 팀이 직접 학습한 scikit-learn 모델(`ai/models/`)이며, 학습 데이터는 AI-Hub 합성 데이터입니다(`ai/README.md`).
